# 세션 옮기기

1. `docs/인수인계.md`의 7장(진행 상황)과 8장(다음 할 일)을 지금 상태로 갱신한다. 이 세션에서 정한 결정이 있으면 6장과 기획서 해당 절에도 반영한다.
2. 이 세션에서 새로 생긴 작업 규칙이 있으면 `CLAUDE.md`에 추가할지 사용자에게 묻는다.
3. 커밋되지 않은 변경이 있으면 커밋 메시지를 제안한다.
4. 새 세션의 첫 메시지로 쓸 문장을 한 줄로 제안한다. 예:
   `docs/인수인계.md를 읽고 8장의 첫 작업부터 이어가자.`
