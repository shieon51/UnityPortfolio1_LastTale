# 오늘 마무리

1. 오늘 한 일을 정리한다. 끝난 것 / 하다 만 것 / 다음으로 넘긴 것.
2. `docs/개발로드맵.md`를 갱신한다.
   - 끝난 작업의 상태를 완료로 바꾸고, 진행 기록 표에 **개발 시간과 디자인·그림 시간을 따로** 적는다. 사용자에게 오늘 각각 몇 시간 썼는지 묻는다(모르면 대략으로).
   - 예상 대비 실제가 20% 이상 어긋나는 일이 쌓이면 남은 작업의 예상(작업일, 개발 4시간 기준)을 다시 계산한다.
   - 로드맵의 "다음 보정 예정" 날짜가 됐거나 지났으면 2주 보정을 한다: 최근 2주 진행 기록에서 실제 하루 평균 개발 시간과 개발 비중을 계산하고, 남은 작업일 × 4 ÷ 실제 하루 개발 시간으로 데모 예상 완료일과 간트를 다시 계산한다. 보정 기록 표에 한 줄 추가하고, 맨 위 설정표와 다음 보정 예정 날짜(+14일)를 고친다.
3. `docs/인수인계.md`의 4·7·8장을 갱신한다.
4. 테스트가 필요한 항목은 `docs/UI기획서.md` 부록 D에 추가한다.
5. 커밋되지 않은 변경이 있으면 커밋 메시지를 제안한다 (커밋은 사용자가 요청할 때만).
6. 내일 할 일을 2~3개 제안한다.
7. 세션을 옮기는 게 좋은 시점이면 한 줄로 알린다.
