# 오늘 시작

1. `docs/개발로드맵.md`와 `docs/인수인계.md`의 7·8장을 읽는다.
2. `git status`로 커밋되지 않은 변경이 있는지 확인하고, 있으면 먼저 알린다.
3. 로드맵 맨 위의 "하루 작업 시간"에 맞춰 오늘 분량을 제안한다.
   - 작업 2~3개. 각각 예상 시간과 끝났다고 볼 기준을 한 줄씩.
   - 사용자가 해야 하는 일(와이어프레임, 테스트, 콘텐츠)과 Claude가 할 일을 구분한다.
   - 사용자의 와이어프레임이나 결정이 있어야 시작할 수 있는 작업은 표시한다.
4. 데모 예상 완료일이 처음 계획보다 늦어지고 있으면 한 줄로 알린다.
5. 사용자가 확인하기 전에는 코드를 고치지 않는다.

답변 형식:

```
오늘 분량 (약 N시간)
1. [작업] — 예상 N시간 / 끝 기준: ...
2. ...
메모: (막힌 것, 사용자가 준비할 것)
```
