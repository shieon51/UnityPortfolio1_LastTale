## 읽는 법

- 예상은 **작업일**(하루 작업 시간 기준) 단위다. 처음 세운 값이라 오차가 크다. 실제 걸린 시간을 진행 기록에 쌓으면서 매주 보정한다.
- 담당: **사용자**(와이어프레임·테스트·콘텐츠·판단), **Claude**(코드·문서), **함께**(Claude가 만들고 사용자가 확인·조정).
- 상태: 대기 / 진행 / 완료 / 보류.
- 아트와 시나리오는 사용자가 코드 작업과 병행한다고 보고 일정에 넣지 않았다. 이 둘이 병목이 되면 데모 일정이 그만큼 밀린다.

## 데모까지의 흐름

```mermaid
gantt
    title 데모까지 예상 일정 (주말 제외)
    dateFormat YYYY-MM-DD
    excludes weekends
    section 기반 시스템
    기록 시스템 2~4단계와 세이브 :a1, 2026-10-09, 12d
    section 와이어프레임
    남은 화면 :b1, 2026-10-09, 7d
    section UI 구현
    화면 프리팹 구현 :c1, after a1, 30d
    section 연출
    연출 시스템 :d1, after c1, 12d
    section 데모 콘텐츠
    리엘 데모 콘텐츠 :e1, after d1, 12d
    section 마무리
    폴리싱 빌드 개발일지 :f1, after e1, 8d
```

와이어프레임(B)은 기반 시스템(A)과 병행한다. UI 구현(C)과 연출(D)도 일부 겹칠 수 있어, 순조로우면 위 일정보다 당겨진다.
